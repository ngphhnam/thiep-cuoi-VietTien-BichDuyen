📊 Kết Nối Google Sheets

Đồng bộ danh sách khách mời và trạng thái "Đã copy" trực tiếp với Google Sheet của bạn để hai vợ chồng cùng theo dõi trên điện thoại.

📋 Hướng dẫn lấy URL trong 1 phút:
  1. Tạo một file Google Sheet mới (Đặt tên ví dụ: Thiệp Cưới 2026).
  2. Vào menu Tiện ích mở rộng (Extensions) → chọn Apps Script.
  3. Dán đoạn mã script (có sẵn trong file hướng dẫn) → Bấm Lưu.
  4. Bấm nút Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment):
    • Chọn loại: Ứng dụng web (Web app)
    • Ai có quyền truy cập (Who has access): Bất kỳ ai (Anyone).
  5. Bấm Triển khai rồi copy đường link Web app URL dán vào ô phía trên!
